# Square Game

An interactive JavaScript mini game where each square demonstrates a different mouse or click-based interaction.

This project was created as a college mini project to practice JavaScript events, DOM manipulation, random number generation, and dynamic styling.

---

## 🔗 Live Demo

👉 [Play Square Game](https://shekharsonawane16.github.io/SquareGame)

---

## 🎮 Game Features

### 1. Random Number
Hover over Square 1 to generate a random number between 0 and 99.

### 2. Color Cycle
Hover over Square 2 to cycle through different colors.

### 3. Random Color
Hover over Square 3 to generate a random RGB color.

### 4. Color Blast
Click Square 4 to generate random colors for the other squares.
